Custom nodes

Flow View supports custom nodes via Web Components and adoptedStyleSheets.

This view is created by the custom-nodes.js example script.

FlowView do not provide a dataflow engine, this example is using the FlowView's brother project dflow. Please keep in mind that this is just an example to showcase custom nodes, there are very few nodes implemented.

If you double click on the canvas and insert a JSON text, it will create an editable node.

Click on a JSON node to edit it. Once the data is changed the graph gets executed and updated.

A special case happens when you insert true or false. You get a toggle node.

Another special case is the output node. You can create by typing an empty string. So double click to open the selector, then press enter.

Other avialable nodes are the if and the + nodes. The + node also supports strings: if you add strings as inputs it will concatenate them.
