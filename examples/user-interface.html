User interface

This view is created by the user-interface.js example script.

  • Double click on canvas to open the prompt.
  • Type into the prompt then press ENTER to create a new node.
  • Drag from a node output to a node input to create a link.
  • Drag on canvas to select items.
  • Click on item to toggle its selection.
  • Click on item while pressing CTRL or CMD to enable multi selection.
  • Drag selected nodes to translate them.
  • Press BACKSPACE to delete selected items.
  • Move pointer while holding SPACE to translate viewport.
  • CTRL or CMD with C, V or Z to copy, paste or undo.
  • CTRL or CMD with D to duplicate selection.
